## CX IN DOCKER

The procedure for any CX project is more or less `gw runDockerContainer`.

Make sure Liferay is running and `${liferay.home}` is valid in the workspace.

If `${liferay.home}` is __not__ the default location (i.e. in the workspace) make sure to also set `liferay.workspace.home.dir` to match the path of your `${liferay.home}`.
